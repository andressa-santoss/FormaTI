# FormaTI — Plataforma de Formação em Tecnologia

## Como executar
1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.
4. Faça login usando qualquer e-mail e senha.

## Fluxo
Login → Dashboard → Trilhas → Selecionar trilha → Biblioteca → Estudo → Quiz → Resultado → Certificado.

## Tecnologias
HTML5, CSS3 e JavaScript puro.

O progresso, nome do usuário, resultado do quiz e certificado são armazenados no `localStorage` do navegador.
